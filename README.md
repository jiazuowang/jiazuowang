## Selected projects

### [Text Review — NLP Desktop Application](https://github.com/jiazuowang/text-review-nlp)

A group NLP project connecting text classification experiments to a local desktop application.

- Proposed the idea and led the initial prototype, from dataset preparation and model experiments to application integration.
- Integrated three trained classifiers with document import, model comparison, batch analysis and report export.
- Published code, model artifacts and evaluation records with team acknowledgements and reproducibility notes.

### [RGB-D Cup Dataset for 6D Pose Estimation](https://github.com/jiazuowang/FoundationPose-dataset-cup)

RealSense D405 captures and custom data loading for NVIDIA FoundationPose.

- Two RGB-D sequences: 116 frames at 1280 × 720 and 234 frames at 640 × 480.
- Connected camera inputs and a Tencent Hunyuan-generated cup mesh to pose registration, tracking and visualization.

### [Product Review Sentiment Classification](https://github.com/jiazuowang/ee6483-sentiment-classification)

Classifier pipelines and experiments developed within an EE6483 group project.

- Compared 19 configurations with grouped cross-validation to keep normalized duplicate reviews together.
- Selected a class-weighted word-and-character TF-IDF SVM using development macro F1.
- Recorded **91.42% accuracy** and **0.8357 macro F1** on a labelled holdout.
- Documented class-wise errors and feature-memory trade-offs.
